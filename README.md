# cs-305
The client for this project was Artemis Financial who own a publicly facing web application. As their application handles file transferring that includes sensitive data, they want to ensure that data being transferred is performed securely. They have requested a checksum verification process to be implemented into their application to ensure that data from one end is being properly sent to the other without any tampering. 
 
One thing I felt was performed well for this project was easily grasping how to update application dependencies. I also found it to be one of the most helpful steps of the process as comparing the vulnerability report before and after showed a vast difference in the quality of protections that were in place for the software. It is important to ensure steps like these are performed in an application like this because it ensures malicious actors cannot cause catastrophic problems for developers as well as clients of those developers. Sensitive data should be treated responsibly, and security is necessary for that.

Security in the application was addressed by ensuring that the checksum implementation was logically sound. Additionally, self-signed certificates were generated using Java’s key tool application to implement a system of trust between the client side and the server side of the application.

Both manual code reviews and static code analyzers were performed to ensure the application was functionally sound before and after changes. Care was taken in the implementation by containing key functionality of the checksum process in try catch blocks of code. Additionally, I did not try to reinvent the wheel when it came to the logic behind how data was encrypted using an AES method which was researched before implementation to ensure it fit the needs of the project.

For some of the portions of the project where I did not have a clear idea how to approach, I utilized resources such as tutorial videos online to serve as a point of reference to move forward with my work. For the implementation of the encryption process, the import used included template code that facilitated the work behind that. I was fortunate to stumble upon that when hovering over the object type as I didn’t know it existed and will likely utilize that knowledge for future projects.

I feel the key thing to show from this project is the screenshot showing proof of encryption through the checksum value. This shows that the data was able to be securely transferred, the most important request of the project, and would lead to a satisfied client. The paper trail of documentation showing the improvements in the vulnerabilities performed through the dependency checker would also be a useful form of proof to show effectiveness at the task. Lastly, I feel the codebase itself, serves as a useful assessment of competency. The work behind the code itself was not great in scale but it was concise and accurately performed the work which shows efficiency as a developer.
